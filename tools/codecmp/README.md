# codecmp

เครื่องมือเทียบโค้ดทั้งโปรเจกต์ระหว่างสองโฟลเดอร์ สำหรับคนที่ต้องตรวจว่า Sandbox กับ Production ต่างกันตรงไหนก่อน deploy หรือก่อน merge โค้ดสองฝั่ง

ต้องใช้ Python 3 อย่างเดียว ไม่ต้องติดตั้ง package เพิ่ม

## วิธีใช้

ดาวน์โหลดโฟลเดอร์ script จาก File Cabinet ของทั้งสอง environment มาไว้ในเครื่อง แล้วรัน:

```bash
python3 codecmp.py <SB_DIR> <PROD_DIR> --by-path --ignore-ws -o <OUT_DIR>
```

| option | ใช้เมื่อ |
|---|---|
| `--by-path` | จับคู่ไฟล์ด้วย relative path **ควรใส่เสมอ** ถ้าไม่ใส่ จะจับคู่ด้วยชื่อไฟล์อย่างเดียว ไฟล์ชื่อซ้ำในคนละโฟลเดอร์จะจับคู่ผิด |
| `--ignore-ws` | ไม่นับช่องว่างและบรรทัดว่างว่าต่าง ใช้เมื่อสองฝั่ง CRLF/LF หรือย่อหน้าไม่ตรงกัน |
| `--ext .js .html` | จำกัดนามสกุลที่เทียบ ถ้าไม่ใส่ จะใช้ชุด default ที่เป็นไฟล์โค้ด |
| `--all-ext` | เทียบทุกนามสกุล |
| `--left-name` `--right-name` | ชื่อที่จะแสดงในรายงาน เช่น `SB1` `PROD` |
| `--context N` · `--max-diff-lines N` | ขนาด context ของ diff และจำนวนบรรทัดสูงสุดต่อไฟล์ |

ถ้ารันบน macOS โดยไม่ระบุโฟลเดอร์ จะเปิด Finder ให้เลือกทีละฝั่ง

## ผลลัพธ์

| ไฟล์ | ผู้อ่าน | เนื้อหา |
|---|---|---|
| `report.md` | คน | สรุปไฟล์ที่เหมือน ต่าง มีฝั่งเดียว |
| `summary.json` | script / agent | รายการเดียวกันในรูป JSON แต่ละไฟล์มี tag สถานะ |
| `diffs/*.diff` | คน | unified diff ของไฟล์ที่ต่าง |
